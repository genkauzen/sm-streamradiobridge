# StreamRadioBridge 1.0.5

Это нативный клиентский слой для Stream Radio. Он не передаёт аудиоданные
через Scrap Mechanic network. Сервер мода синхронизирует URL, `PLAY/STOP`,
loop и позицию, а каждый клиент отдельно:

1. получает тот же URL;
2. потоково читает аудиодорожку через `yt-dlp.exe` без ожидания полного файла;
3. на лету переводит поток в Ogg через `ffmpeg.exe`;
4. отдаёт Ogg через локальный loopback HTTP-сервер в FMOD;
5. привязывает канал к позиции радио и обновляет 3D listener;
6. корректирует drift по серверной позиции.

Listener берётся из позиции и направления камеры Scrap Mechanic. Используется
right-handed система координат игры, squared rolloff от 1,5 до 35 метров и
нулевой Doppler scale, поэтому движение не замедляет и не ускоряет музыку.

Видео не создаётся и не рендерится.

## Сборка

`build-bridge.ps1` собирает:

- `bin/StreamRadioBridge.dll`;
- `bin/StreamRadioBridgeInject.exe`.

## Запуск

В готовом дистрибутиве запускайте `StreamRadioLauncher.bat` из корня: он
откроет Scrap Mechanic через Steam, дождётся процесса и передаст инжектору
абсолютный путь к DLL. Для ручного запуска из этой папки:

```text
StreamRadioBridgeInject.exe StreamRadioBridge.dll
```

Инжектор должен быть запущен на каждом клиентском компьютере, который должен
слышать радио. Для dedicated/server state достаточно Lua-мода; звук создаётся
локально у каждого игрока.

После смены мира неактивные каналы освобождаются автоматически. Интерфейс радио
содержит вкладки `РАДИО` и `ПОИСК YOUTUBE`; отдельной вкладки Bridge нет.

`yt-dlp.exe` и `ffmpeg.exe` уже лежат рядом с DLL в дистрибутиве.

## Ограничения

- требуется закрыть игру перед заменой DLL;
- одновременно допускается только одна версия StreamRadioBridge в процессе;
- YouTube/TikTok/VK могут менять правила доступа и требовать обновления yt-dlp;
- для воспроизведения нужен `ffmpeg.exe` рядом с DLL; он используется только
  для audio-only конвертации, видео не выводится;
- это отдельный FMOD system, поэтому физическое затухание рассчитывается
  локально на каждом клиенте по позиции радио и игрока;
- старый `SM-CustomAudioExtension` 0.7.4 не используется.
