# Stream Radio Core — Scrap Mechanic 1.0.x

Это Lua/GUI-часть Stream Radio для Scrap Mechanic 1.0.5. Вместе с нативным
`StreamRadioBridge` из полного дистрибутива она образует рабочий URL-плеер:

- замена vanilla Radio и vanilla Boombox по их UUID на StreamBoombox;
- отдельный Stream Boombox с `stackSize: 1` как запасной предмет;
- у каждого экземпляра радио своя очередь и свой плеер; сервер является авторитетным источником состояния;
- play/pause, stop, previous/next, loop, очередь и серверная позиция трека синхронизируются между игроками только внутри одного радио;
- при PLAY сервер включает `interactable.active`, при STOP выключает его;
- при наличии duration от native bridge появляется динамичная дорожка позиции и перемотка;
- при подключении к выходу сиденья устройство появляется в панели сиденья как `seated`-кнопка;
- нажатие кнопки сиденья открывает настройки радио;
- громкость не отправляется на сервер и меняется отдельно у каждого игрока;
- видео не создаётся и не отображается — предусмотрен только audio-only режим и заглушка превью; динамическая thumbnail-картинка появляется только при наличии native bridge с необязательным `getPreviewImage`.

## Нативный мост

Чистый Lua API Scrap Mechanic не умеет выполнять HTTP-запросы, скачивать аудио,
запускать `ffmpeg`/`yt-dlp` или передавать URL в `sm.audio`. Поэтому для звука
запускайте игру через `StreamRadioLauncher.bat` из полного дистрибутива.
Без моста интерфейс и синхронизация работают, но URL-аудио не декодируется.

В дистрибутив уже включены DLL и инжектор, собранные и проверенные на Scrap
Mechanic 1.0.5, а также `yt-dlp` и `ffmpeg`. Старый SM-CustomAudioExtension из
community-мода 0.7.4 для этой сборки не используется.

## Установка

1. Запустите `StreamRadioLauncher.bat` рядом с этой папкой.
2. Нажмите `Проверить`, `Установить / обновить`, затем `START`.
3. Включите `Stream Radio Core` в настройках мира.
4. В Creative найдите `Stream Radio Core / Stream Boombox`.
5. В Fant Mod 3 включите оба мода. В Fant 3 рецепт находится в корневом
   `CraftingRecipes/craftbot.json` и должен появиться в Craftbot после перезапуска мира.
6. Соедините Stream Boombox с выходом сиденья. В панели сиденья появится
   дополнительная кнопка; её нажатие открывает радио.

## Замена vanilla Radio и Boombox

Мод содержит shape entries с UUID vanilla Radio (`dfefc9d7-db03-4d25-ad85-eae1d824d8c0`)
и vanilla Boombox (`03bdd942-c808-4795-aa0b-554fa98c3c74`). Новые предметы
получают класс `StreamBoombox`. Уже сериализированный в сохранении shape может
остаться с ванильным классом: API 1.0.5 не даёт модификации безопасно заменить
его на лету. Если старый блок продолжает работать как vanilla, удалите только
этот радиоблок и поставьте его заново после включения мода; папку `Cache` можно
очистить лаунчером автоматически.

## Проверка

Creative с включённым модом и загрузка нативного моста проверены на версии
1.0.5. Для мультиплеера каждый игрок, который должен слышать радио, запускает
свою копию игры через BAT: сервер синхронизирует состояние, а звук загружается
и воспроизводится локально.

Обычные ролики и аудиоссылки YouTube/TikTok/VK обрабатываются через `yt-dlp`.
Доступность конкретной ссылки зависит от региона, авторизации и правил сервиса.
Бесконечный live-поток в этой версии не гарантируется: мост ожидает завершения
audio-only загрузки до 90 секунд. Видео никогда не рендерится.

Ответственность за права на музыку, соблюдение правил YouTube/TikTok/VK и лимиты сервисов остаётся у владельца сервера/игрока.
